EuroPriv-Bench: A Unified Pan-European De-identification Benchmark with Re-identification Risk Metrics

Paper 1 preprint by KlusAI, licensed under Apache-2.0.

- `paper1.pdf`: compiled manuscript.
- `paper1-arxiv.tar.gz`: self-contained TeX source, generated `.bbl`, bibliography,
  and referenced local assets; rebuilt in isolation with the pinned Docker TeX toolchain.

Validation follows the RES-77 LLM-panel protocol, not native-speaker human validation.
This manuscript does not claim a completed panel outcome. The current manuscript still
has unfilled taxonomy, construction, metrics, and baseline sections; the build checks
establish source portability, not scientific completeness.
